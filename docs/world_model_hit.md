# 动作条件的击球结果模型 H1

已完成第一版训练：过去 0.4 秒的 9 帧顶视 RGB，加一个计划中的左臂击打动作，输出预测物理接触后 1 秒的世界 XY，每 0.05 秒一个点，并预测实际接触相对计划接触的延迟。当前仅适用于现有专家左臂击球分布，尚不是动作选择策略。

## 数据与动作语义

- 100 条 episode，复用 RGB V4 的完整 seed 划分 70/15/15；每条取 4 个不同击球前观察时刻，280/60/60 个窗口，窗口不是独立 episode。
- 最后一帧截止于 `prep_time - 0.02s - offset`，offset 为 0、0.05、0.10、0.15 秒。
- **`prep_time` 是从开始到准备运动结束的时长，也是快速挥击开始的时间，绝非整个动作开始时刻。** 画面可能已经展示该专家动作的准备运动，因此当前对照不能用于证明对完全新候选动作的因果泛化。所有画面仍早于真实击球。
- 六维动作：计划接触相对观察时刻的延迟（秒）、计划球接触 X/Y（按桌面尺度归一化）、挥击方向 cos/sin、击球器计划速度（m/s）。角度是 `nominal_theta_deg + direction_correction_deg`；坐标只接受左臂 `world`，未适配右臂旋转坐标。
- 接触 X/Y 是计划的球接触点，不是夹具位置；速度是击球器速度，不是期望球速。
- 仅白名单读取计划字段。实际接触时刻、击球后速度、得分、物理参数、未来球状态和未来 RGB 都不进入网络输入。动作来自已选专家计划，候选搜索输出当时可以使用，但当前动作分布本身由真值专家选择。
- HDF5 图像沿用 `decode_image_bit`，按 20 Hz 状态时钟读取，不将 50 FPS 视频假定为等长状态序列。
- 实际左接触时间只用于标签与延迟监督。位置标签在接触后按固定间隔查询，线性插值不跨越左/右臂接触，不外推。右臂接触前 0.02 秒后全部屏蔽，绝不把右臂第二次击球解释成左动作效果。

## 模型与训练

冻结 RGB V4 来球模型，提取其 RGB 预测的历史位置和自由运动轨迹，再以 64 维 MLP 融合动作与未来时间，预测接触延迟和击打后的轨迹。缓存的是 RGB 模型输出，不是真值位置或速度。骨干和所有部署权重都包含在 checkpoint 中。

动作模型及相同结构的无动作对照各训练 150 轮，按验证集 ADE 选择第 141 / 116 轮。验证集动作模型 ADE 6.62 cm，对照 11.18 cm；测试结果不用于挑选轮次。

训练目录：`outputs/world_model_hit/run_20261011_112552_482301/`。

| 测试指标 | RGB + 动作 | 同结构无动作 |
| --- | --- | --- |
| 有效预测点平均误差 | 4.95 cm | 7.30 cm |
| 接触后 0.1 秒误差 | 3.66 cm | 5.10 cm |
| 接触后 0.3 秒误差 | 4.39 cm | 6.94 cm |
| 接触后 0.5 秒误差 | 6.17 cm | 9.07 cm |

整体误差改善约 32%。动作模型测试点误差 95 分位 12.06 cm；把动作替换为别的 episode 的动作，ADE 14.54 cm。这证明模型对动作敏感，并不证明改变动作后预测一定符合真实物理。

0.1/0.3 秒测试各 60 个窗口（15 条 episode），0.5 秒 56 窗口（14 条），1 秒仅 4 窗口（1 条）；不将 1 秒的 4.22 cm 作为充分长时程证据。训练集 1 秒也只有 16 窗口（4 条）。后续需要补采延迟/取消右臂击球的长尾数据及同状态多动作实验。

## 运行与接口

使用已有 RoboTwin Python 环境，在仓库根目录执行：

```bash
python scripts/train_world_model_hit.py --device cuda
PYTHONPATH=. python -m unittest tests.test_world_model_hit tests.test_world_model_rgb -v
```

配置：`env_cfg/world_model_hit.yml`。新运行写独立目录，校验骨干数据 SHA256、输入配置并保留原 seed 划分。实际训练峰值 PyTorch 已分配张量显存约 721 MiB，不含桌面、渲染及缓存保留显存。

```python
from world_model.hit_inference import HitTrajectoryPredictor

predictor = HitTrajectoryPredictor(
    'outputs/world_model_hit/run_20261011_112552_482301/action_best.pt', device='cpu')
# rgb_history 为按 0.05 秒间隔采样的连续 9 帧 RGB uint8，T,H,W,3。
# plan 为计划动作白名单字段，时间与 decision_s 采用同一时钟。
# decision_s 是最后观察帧的时刻；必须早于计划快速挥击的开始。
result = predictor.predict(rgb_history, plan, decision_s)
print(result['predicted_contact_time_s'])
print(result['absolute_times_s'], result['xy_m'])
print(result['training_support_windows'])
```

部署时预测物理接触时间为计划时间加网络预测延迟，无需真实接触事件作为输入。输出描述一次左动作及其随后自由运动，不能越过未知的下一次机器人击打继续使用；`training_support_windows` 提醒各时长的训练覆盖，不是置信度或未来碰撞掩码。

原始 RGB 回放接口输出有限 20×2 坐标，与缓存特征评测路径最大差约 0.00000027 m。接触时间预测 MAE 2.54 ms；在模型预测的实际时钟上查询真实轨迹，平均误差 4.92 cm（738 个有效点），不是仅依赖真实接触对齐的结果。CPU 四线程含 RGB 缩放/模型推理约 6.58 ms，不含解码、渲染或机械臂执行。

验证：完整项目测试 43 项，37 通过、6 条件跳过；新增 4 项测试覆盖输出字段隔离、接触插值边界、RGB 时序、冻结骨干与动作消融。实际推理还检查了原始 RGB、预测时钟及不完整历史拒绝。

## 下一步
